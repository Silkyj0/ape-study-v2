## Provenance model
Module 5 differs from Modules 3–4 because the PARC guide expressly says that several evolving topics should be read from current external sources rather than Acumen alone.

Two QA statuses are therefore used:
- **Drive source verified** — proposition checked directly against a supplied M5 PDF and the Drive file ID/URL retained.
- **PARC external source verified** — proposition checked against a current public resource explicitly identified in the PARC M5 reading guide and the exact URL/check date retained.

The external-source status is not permission to fill gaps from general knowledge. Only the sources specifically directed by the supplied PARC guide are used for these questions.
